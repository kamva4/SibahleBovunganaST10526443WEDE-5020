## Part 1 Details

## Part 1 – Building the Foundation

Part 1 focused on planning and developing the basic structure of the Coffee&Beans website before applying advanced styling.

### Organisation

Coffee&Beans is a fictional coffee shop based in Johannesburg, South Africa, with café locations in Braamfontein and Melville. The business was founded in 2019 by Thandiwe Mokoena. The website is designed to promote the café, its menu and its services to busy customers in Johannesburg.

### Purpose of the Website

The purpose of the website is to provide customers with information about Coffee&Beans, including its menu, café locations, contact details and enquiry options. The website also introduces customers to South African-inspired food and drink options offered by the café.

### Target Audience

The target audience is mainly busy professional women in Johannesburg who are looking for convenient, quality coffee, light meals and quick breakfast options.

### Website Pages

The website consists of five main HTML pages:

- Home (`index.html`)
- Menu (`menu.html`)
- About Us (`about_us.html`)
- Enquiry (`enquiry.html`)
- Contact (`contact.html`)

### Part 1 Development

The following were completed during Part 1:

- Organisation and website concept selected.
- Project proposal developed.
- Website content researched and planned.
- Website sitemap and file structure planned.
- Wireframes and page layouts planned.
- Five HTML pages created.
- Navigation links created between the pages.
- Images and website content added.
- Website folder structure organised.
- GitHub repository created for the project.

Part 1 focused primarily on establishing the HTML structure, content and navigation of the website.

## Part 2 – Styling the Website with CSS

Part 2 focused on improving the visual appearance, layout, usability and responsiveness of the Coffee&Beans website using CSS.

### CSS Implementation

An external CSS stylesheet was created and linked to the website pages. CSS was used to create a consistent visual identity across the website.

The styling included:

- CSS reset to provide consistent default styling.
- Typography and text formatting.
- Consistent colours and fonts.
- Responsive page containers and sections.
- Styled buttons and links.
- Header and navigation styling.
- Active navigation indicators.
- Mobile navigation menu.
- Footer styling.
- Hero section styling.
- Image sizing and positioning.
- Product cards.
- Menu grids.
- Search bar styling.
- Form styling.
- Spacing, padding and margins.
- Rounded corners and other decorative styling.
- Responsive design using media queries.

### Responsive Design

Media queries were used to make the website responsive on smaller screens. The menu layout changes on mobile devices so that the content and product cards can be displayed clearly without requiring horizontal scrolling.

The website was tested at different screen sizes to improve usability on both desktop and mobile devices.

### Menu Page

The Menu page was styled using a responsive grid layout. Products are displayed as individual cards containing images, descriptions and prices. The menu includes coffee, South African favourites, pastries and light meals.

### Website Consistency

CSS was used across the website to maintain consistent branding, spacing, colours, typography, buttons, navigation and page layouts.

Part 2 therefore transformed the basic HTML structure developed in Part 1 into a more visually organised, responsive and user-friendly website.
